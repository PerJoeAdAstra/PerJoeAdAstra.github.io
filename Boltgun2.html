Warhammer 40,000: Boltgun 2

Platforms: Steam, Steam deck verified, Playstation 5, Xbox series X, Switch 2
Technology: Unreal Engine 5, C++, Blueprints
Duration: 2 Years

Warhammer 40,000: Boltgun 2 is a first-person shooter developed by Auroch Digital and published by Big Fan Games. It is set in the Warhammer 40,000 universe and is a direct sequel to Warhammer 40,000: Boltgun.

I worked on a wide variety of systems across the project from early production through to release. Notable inclusions are

  • Responsible for all of the UI programming, using Slate, UMG and integrating Common UI to add UI functionality including multiplatform support.
  • Updated the FSM based AI to use a new modular AI action system and collaborated with the design team to assist them setting up many new AI behaviours
  • Used editor tools to create editor visualisers and asset validators to help catch issues before they became problems at runtime
  • Refactored the existing codebase to be more extendable and maintainable, converting many interlocking monolithic elements into more modular components and subsystems.
